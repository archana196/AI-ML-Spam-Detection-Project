# 📩 Spam Detection using Machine Learning

## 📌 Problem Statement
Spam messages are a common issue in communication systems.  
This project aims to classify messages as spam or not using machine learning.

---

## 🎯 Objective
- Detect spam messages accurately  
- Apply NLP techniques for text processing  
- Compare model performance  

---

## 📂 Dataset
- SMS Spam Collection Dataset  

---

## ⚙️ Methodology

### 🔹 Text Preprocessing
- Tokenization  
- Stopword removal  
- Text vectorization (TF-IDF / CountVectorizer)  

### 🔹 Model Building
- Trained models like:
  - Naive Bayes  
  - Logistic Regression  

---

## 📊 Results
- Accuracy: 92%   
- Precision: High  
- Recall: High
